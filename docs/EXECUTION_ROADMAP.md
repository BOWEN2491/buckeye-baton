## 已确认的最终蓝图

Project 是核心，卡片是浏览展示。保留既有三状态经验、所有者编辑和历史。最终流程：浏览 → 接棒 → 新项目 → 提问 → Staff 引荐 → Mentor 回复 → 后续成果。新增 AI 只生成浏览简介和标签，不代写经历。
deadline 指具体求助希望获得回复的时间。最终自动站内邀请会限制频率；当前不发送任何邀请。产品 UI、按钮、错误提示、测试预期文案统一英文；Mentor workload 下用 Awaiting reply 显示待回复数。

## 分工

- Worker A：数据库、服务端 API、校验、权限、样例、后端测试；首先交付共用类型。
- Worker B：页面、交互、样式、浏览器测试；使用契约开发，不另写业务规则。
- 总控：契约与范围、依赖/共用文件变更批准、进度核验、分支集成、独立审查、最终构建验收与 PR。
- Worker 不互相覆盖、不合并 main、不自行发布线上服务、不接入收费资源。
- 文档和设计中的未确认扩展不自动纳入：共同所有者、自动延续 Mentor、Ongoing 接棒、选择性复制与帖子编辑删除留后续决策。

## 分支与同步顺序

main 是共享稳定基线；codex/p1-integration 是本轮临时集成分支。
A 从远程集成分支建立 codex/p1-api，B 建立 codex/p1-ui；各用自己的仓库/目录，不共享 .data 或构建目录。

1. A 先只提交契约对应的 src/shared/relay-types.ts，单独提交并推送，回传 SHA，然后继续后端。
2. B 同时做布局与组件外壳。总控核对 A 的类型提交后，将其以原提交合入并推送集成分支。
3. B 保存本分支工作后 fetch 并 merge origin/codex/p1-integration，获得同一份类型，再接入 fixture/API；不要自行复制另一份类型，不 cherry-pick 不明来源提交。
4. A/B 完成可验收小批次后各自 push，回传 SHA、文件与检查结果；不要相互 merge 分支。契约有问题先报告总控。
5. 总控先集成 A，再集成 B，验证真实页面与数据链路。只在通过后创建最终 PR；合并后清理临时分支。

## P1 十个功能验收门槛

每项经总控独立核验通过记 10%，worker 自报完成/提交代码不自动计分。
- [ ] G1：三种接棒方式创建新 Ongoing，重复提交同一 requestId 不重复创建。
- [ ] G2：来源与后续双向展示正确，原项目和所有者不变。
- [ ] G3：项目内学生提问及可选回复期限持久保存；无需 Mentor 的讨论不进入 Staff 待办。
- [ ] G4：问题内平铺评论与提问者追问归属正确，不跨项目串线。
- [ ] G5：Staff 手动引荐且每问题一条，重复/并发引荐冲突明确。
- [ ] G6：指定 Mentor 能正式回复并继续回应，非指定用户不能伪造正式回复。
- [ ] G7：工作台准确流转；明确追问重新待回复，普通评论/感谢不改变待回复负载。
- [ ] G8：权限、非法输入、日期与链接、失败输入保留及明确提示通过。
- [ ] G9：刷新/重启/增量迁移后记录和旧历史保留，状态变化不关闭问题，旧采用接口仍 410。
- [ ] G10：生产构建、完整四身份页面旅程、390px 布局及浏览器无异常通过。

目前：P0 已完成；P1 0/10（0%）；P2–P4 未开始。契约文档准备不计作功能通过。

## 回传与进度格式

每个小批次或遇阻时回传：worker 名称、分支、最新 SHA、完成行为、改动文件、运行命令及真实结果、待办和阻塞。截图/测试证据要给路径或可访问链接。不要只写“完成 80%”。

总控报告示例：P1 通过 6/10 项，60%；A：接口已核验；B：角色页待接入；当前阻塞：正式回复定位；下一步：跑四身份旅程。
外部 worker 的实时状态无法自动读取，需用户把回传发回当前对话，或提供可访问的分支提交。

为减少转抄，A/B 可把结果分别写入专属 REPORT_A.md / REPORT_B.md 并随任务分支 push。用户只需说“A/B 已推送”，总控随后 fetch 分支核对报告与实现。未收到触发消息时，不宣称正在后台持续监控。

## P2–P4 后续批次

- P2：A 做结构化 AI 服务/结果存储/失败回退与队列汇总；B 做简介编辑确认、卡片标签和 Staff 的 Mentor workload 展示。先明确服务凭据，不能假装调用成功。
- P3：A 做可解释排序和时间规则；B 做推荐原因、筛选和作者建议。长时间无人接棒不等于问题无人回复，不能伪造“无解概率”。
- P4：A 做持久通知/任务、邀请去重限频及匹配；B 做站内 inbox、接受/忽略和关闭自动邀请设置。不发送外部邮件。
每一级先定验收条目和契约，再分工；前一级未通过不把后一级半成品混进主流程。
