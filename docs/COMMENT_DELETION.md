# P2 产品验收补充：项目评论删除

2026-10-24。用户反馈P2其他功能验收通过，新增：项目所有者可以删除项目内任意评论，评论作者可以删除自己的评论。本补充取代旧规格中“本轮不做帖子删除”的限制，main合并仍需单独授权。

## 行为与权限

- 覆盖项目问题下的comment、follow_up、mentor_reply。Project owner 指项目所有者；提问者不因此获得删除别人评论的权力。Staff/Mentor也只能删除自己发布的评论，除非他们本身是项目所有者。
- 本次不删除问题本身、项目或引荐记录，不增加评论编辑或恢复按钮。旧Lesson讨论不扩展删除。
- 仅获授权的身份看到Delete；点击需确认；请求中禁用重复操作；失败保留评论并显示错误。正式回复/追问的确认框提示可能改变待回复状态。
- 服务端重新校验身份和项目/评论归属，不能靠客户端隐藏按钮代替权限。

## API与存储

`DELETE /api/project-posts/:id` 使用既有demo header，成功200 `{data: QuestionThread}`，无身份401、非作者且非项目所有者403、记录不存在404。合法重复删除200，保留最初删除记录。

增量添加project_posts.deletedAt与deletedBy。保留原body及审计记录；所有公开讨论、个人工作台和Mentor负载的共用读取排除deletedAt非空行，API不返回删除元数据或已删除正文。不重置表、不清理历史数据。

删除普通评论不影响队列；删除最后一次正式回复可能恢复Awaiting reply；删除追问可能恢复之前的Replied。状态仍按剩余有效帖子createdAt/id顺序推导，不能简单地删除一条就加减固定数量。原问题和引荐继续存在。
