当前架构

浏览器访问本机 5173 端口，React 表单向相对路径 /api/echo 发出 POST。Vite 将 /api 转发至 8000 端口的 FastAPI，后端校验并去除文字首尾空白后返回回显和字符数；React 更新成功或错误状态。备用 Streamlit 独立运行在 8501 端口。OpenAI 仅由独立命令行检查脚本主动调用，不在默认页面链路中。没有数据库或云端服务；静态前端构建不能代替 Python 后端部署。

入口与接口

  • Windows：start.ps1；前端：frontend/src/main.jsx；后端：backend.main:app。
  • GET /api/health 返回正常状态。
  • POST /api/echo 请求字段 text，长度 1–2000 且非全空白；无效返回 422。
  • 请求 {"text":"Hello"} 返回 {"result":"Hello","characters":5,"mode":"practice"}。
  • 备用：fallback/app.py。FastAPI 文档路径 /docs。
