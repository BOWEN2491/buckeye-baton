| 目录 | 使用方式 |

## 原型与当前批准规则的差异

| 主题 | 当前仓库规则 | 原型新增内容，尚待统一 |
|---|---|---|
| 项目来源 | Finished/Paused 提供接棒入口 | Ongoing 也能接棒、首页卡片直接接棒 |
| 编辑权限 | 单个学生所有者 | 加队友即成为共同所有者 |
| 导师连接 | Staff 针对问题人工引荐 | 原 Mentor 自动延续，支持绕过 Staff |
| 状态内容 | 保存并保留旧总结 | 描述为“覆盖”，但是否仅隐藏旧数据未定 |
| 来源材料 | 保留来源链接 | 并排查看，逐项复制/改写并标注出处 |
| 讨论操作 | 平铺问题与回复 | 导师请求选择、追问重新进入待办、帖子编辑删除 |

下一轮实施前集中修改 MVP_SPEC、接口和验收；不直接以原型中的示例接口替代运行契约。自动推荐 Mentor、AI 简介、独立 Lesson、逐条采用与成功统计继续排除。
