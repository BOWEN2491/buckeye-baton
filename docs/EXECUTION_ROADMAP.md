## 回传与进度格式

低频汇报规则：正常只转交一次——完整 P2 实现、自测和推送结束后，使用 P2_AGENT_TASK.md 的 READY 短块；详细结果放 docs/P2_REPORT.md。中间提交不要求回传，不按固定时间催报，也不要求复制完整会话。

总控报告示例：P2 已验收 6/10 项，60%；负载接口已核验；真实AI与页面待核验。仅按已独立验证门槛计分，不按代码量估计。
外部 worker 的实时状态无法自动读取，需用户把回传发回当前对话，或提供可访问的分支提交。

总控收到短块后 fetch 分支，核对 docs/P2_REPORT.md 与实现。需要改变契约/依赖/权限、分支冲突、推送失败或两次尝试仍无法继续时才额外使用 BLOCKED 短块；总控要求返修后，修复完成再回报一次。未收到触发消息时，不宣称正在后台持续监控。
