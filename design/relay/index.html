Edge states

  • No questions yet
  • No mentors in the directory (referral form)
  • Baton form submit fails: set "Next submit" to Fails, then submit
  • Referral submit fails, and already referred by someone else
  • Reply submit fails (text is kept)
  • Project Paused after the discussion and Finished: the thread is kept
  • Another mentor's view: regular comment only
  • A question that didn't ask for a mentor: open discussion, not in the Staff workbench
  • Edit or delete your own post (Mia's follow-up), and delete a question before anyone replies
  • Change status: click "Change status" (Ongoing → Paused / Finished, and back to Ongoing). The new status's content replaces the old one
  • Baton form from a Finished project
  • Picked up from a Finished project and from an Ongoing project (mentor continues)
