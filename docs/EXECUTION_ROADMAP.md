## 已确认的最终蓝图

Project 是核心，卡片是浏览展示。保留既有三状态经验、所有者编辑和历史。最终流程：浏览 → 接棒 → 新项目 → 提问 → Staff 引荐 → Mentor 回复 → 后续成果。新增 AI 只生成浏览简介和标签，不代写经历。
deadline 指具体求助希望获得回复的时间。最终自动站内邀请会限制频率；当前不发送任何邀请。产品 UI、按钮、错误提示、测试预期文案统一英文；Mentor workload 下用 Awaiting reply 显示待回复数。

## 分工

- P1 实现 Agent：共用类型、数据库、API、权限、样例、正式页面、后端与浏览器测试，连续完成整条旅程。统一任务书见 [P1_AGENT_TASK.md](P1_AGENT_TASK.md)。
- 总控：契约与范围、依赖/共用文件变更批准、进度核验、分支集成、独立审查、最终构建验收与 PR。
- Worker 不互相覆盖、不合并 main、不自行发布线上服务、不接入收费资源。
- 文档和设计中的未确认扩展不自动纳入：共同所有者、自动延续 Mentor、Ongoing 接棒、选择性复制与帖子编辑删除留后续决策。

## 分支与同步顺序

main 是共享稳定基线；codex/p1-integration 是本轮临时集成分支。
实现 Agent 从 origin/codex/p1-integration 建立 codex/p1-implementation，使用独立克隆目录，不共享 .data 或构建目录。旧 A/B 任务书已被单 Agent 任务取代。

1. 先实现共用类型，再连续完成增量数据库、API、正式页面与测试，无需中途类型交接。
2. 可以小批次提交和 push，正常只在完整 P1 实现与自测结束后回传一次 READY 短块；详细报告随分支保存为 docs/P1_REPORT.md。
3. 总控 fetch 对应提交，独立验证 G1–G10，再集成；需要返修时集中反馈。
4. 只在验收通过后创建最终 PR；不由实现 Agent 合并 main。合并后清理临时分支。

## P1 十个功能验收门槛

每项经总控独立核验通过记 10%，worker 自报完成/提交代码不自动计分。
- [ ] G1：三种接棒方式创建新 Ongoing，重复提交同一 requestId 不重复创建。
- [ ] G2：来源与后续双向展示正确，原项目和所有者不变。
- [ ] G3：项目内学生提问及可选回复期限持久保存；无需 Mentor 的讨论不进入 Staff 待办。
- [ ] G4：问题内平铺评论与提问者追问归属正确，不跨项目串线。
- [ ] G5：Staff 手动引荐且每问题一条，重复/并发引荐冲突明确。
- [ ] G6：指定 Mentor 能正式回复并继续回应，非指定用户不能伪造正式回复。
- [ ] G7：工作台准确流转；明确追问重新待回复，普通评论/感谢不改变待回复负载。
- [ ] G8：权限、非法输入、日期与链接、失败输入保留及明确提示通过。
- [ ] G9：刷新/重启/增量迁移后记录和旧历史保留，状态变化不关闭问题，旧采用接口仍 410。
- [ ] G10：生产构建、完整四身份页面旅程、390px 布局及浏览器无异常通过。

目前：P0 已完成；P1 0/10（0%）；P2–P4 未开始。契约文档准备不计作功能通过。

## 回传与进度格式

低频汇报规则：正常只转交一次——完整 P1 实现、自测和推送结束后，使用 P1_AGENT_TASK.md 的 READY 短块；详细结果放 docs/P1_REPORT.md。中间提交不要求回传，不按固定时间催报，也不要求复制完整会话。

总控报告示例：P1 已验收 6/10 项，60%；引荐接口已通过；角色页待核验；下一步：跑四身份旅程。
外部 worker 的实时状态无法自动读取，需用户把回传发回当前对话，或提供可访问的分支提交。

总控收到短块后 fetch 分支，核对 docs/P1_REPORT.md 与实现。需要改变契约/依赖/权限、分支冲突、推送失败或两次尝试仍无法继续时才额外使用 BLOCKED 短块；总控要求返修后，修复完成再回报一次。未收到触发消息时，不宣称正在后台持续监控。

## P2–P4 后续批次

- P2：结构化 AI 服务、结果存储、失败回退、简介编辑确认、卡片标签和 Staff 的 Mentor workload 展示。先明确服务凭据，不能假装调用成功。
- P3：可解释排序、时间规则、推荐原因、筛选和作者建议。长时间无人接棒不等于问题无人回复，不能伪造“无解概率”。
- P4：持久通知/任务、邀请去重限频、匹配、站内 inbox、接受/忽略和关闭自动邀请设置。不发送外部邮件。
每一级先定验收条目和契约，再分工；前一级未通过不把后一级半成品混进主流程。
